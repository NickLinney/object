# NickLinney Abstract Object Package Structure

This package is a reusable directory-tree and governance template for a NickLinney Skill Context Packet or another governed Object package.

It defines the minimum package roles without claiming that every Object is a Skill. A Skill normally uses `SKILL.md` as its entrypoint. A Prompt Template, Schema, Process Specification, Diagram Object, Tool, Registry, or other Object must select a faithful entrypoint and retain the same provenance, contract, lifecycle, validation, and manifest principles.

Copy this root, rename it to the Object slug, replace the placeholders, and preserve the root directory when creating the ZIP.
