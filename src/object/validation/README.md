# Validation Template

Record structural checks, schema checks, semantic checks, render checks where applicable, behavioral checks where independently executed, falsification conditions, abstentions, failures, and unresolved gaps.

Validation evidence must distinguish `STRUCTURAL_PASS`, `JSON_PARSE_PASS`, `SCHEMA_CONFORMANCE_PASS`, and `INTEGRITY_PASS`. A passing package validation record proves only the checks it lists; it does not prove behavioral execution, authorization, activation, deployment, or production use.
