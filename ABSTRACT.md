# Abstract Object Package Structure

The Abstract Object Package Structure is a portable serialization convention for governed Objects.

Its semantic roles include identity and entrypoint material, abstract and implementation specifications, contracts, provenance, composed Objects, instantiations, references, schemas, deterministic scripts, and validation evidence. Roles must be accounted for, while physical materialization remains conditional on applicability.

The package does not claim that every Object is a Skill or executable capability. Candidate, recommendation, authorization, construction, validation, installation, activation, deployment, canonical approval, and production execution remain separate lifecycle states.
