# Versioning

This project follows Semantic Versioning with explicit early-lifecycle phases.

- Pre-alpha snapshots: `0.0.0-pre-alpha.N`
- First alpha release: `0.1.0-alpha`
- Beta releases: `0.MINOR.0-beta`
- Release candidates: `MAJOR.MINOR.PATCH-rc.N`
- Stable releases: `MAJOR.MINOR.PATCH`

Versions are set during release preparation. Tagged releases are immutable snapshots.
